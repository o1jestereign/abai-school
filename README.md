# 🏫 Абай атындағы дарынды балаларға арналған мектеп (Қызылорда)
## 2D Ішкі Навигация Жүйесі & Digital Twin

Заманауи, мобильді құрылғыларға бейімделген мектептің интерактивті 2D ішкі навигация жүйесі. 
Оқушылар, мұғалімдер және қонақтар үшін кез келген кабинетке, асханаға немесе спорт залға дейінгі ең қысқа маршрутты салып береді.

---

## ✨ Негізгі Мүмкіндіктер

- 🏢 **3 Қабатты Архитектуралық Карта:** Мектептің нақты жобасы (1, 2, 3-қабаттар, баспалдақтар, есіктер мен дәліздер).
- 🧭 **Ақылды Маршрут (Dijkstra Algorithm):** Іздеуден қалаған орынды таңдасаңыз, ең қысқа әрі дұрыс жолды анимациямен сызып береді.
- 🧱 **16-бағытты Қабырға Физикасы:** Персонаж қабырғадан өтпейді, бұрыштардан табиғи сырғиды және есіктерден оңай өтеді.
- 📱 **QR-код арқылы Навигация:** Мектептегі QR-кодты телефон камерасымен сканерлегенде сайт бірден сол орыннан (кіреберіс, асхана, спортзал т.б.) ашылады.
- ⚡ **Жылдам әрі Жеңіл:** Серверлік ауыр талаптар жоқ, кез келген браузерде (Chrome, Safari, Edge, Firefox) ұшып жұмыс істейді.

## 🚀 GitHub Pages-ке 1 минутта тегін қосу (Hosting)

Бұл жоба толықтай статикалық болғандықтан, оны **GitHub Pages** арқылы тегін әрі сенімді хостингке қосуға болады:

1. **GitHub-та жаңа репозиторий ашыңыз:**  
   - Аты: мысалы, `abai-school`
   - Public ретінде жасаңыз.
2. **Кодты жүктеңіз (Push):**
   ```bash
   git remote add origin https://github.com/<СІЗДІҢ_АККАУНТ>/abai-school.git
   git branch -M main
   git push -u origin main
   ```
3. **GitHub Pages-ті қосыңыз:**
   - Репозиторийдің **Settings** бөліміне өтіңіз.
   - Сол жақтағы мәзірден **Pages** таңдаңыз.
   - **Branch** деген жерден `main` және `/ (root)` таңдап, **Save** түймесін басыңыз.
4. **Дайын!** Бірнеше секундта сіздің сайтыңыз `https://<СІЗДІҢ_АККАУНТ>.github.io/abai-school/` мекенжайында жұмыс істеп тұрады.

## 📷 QR-Кодтар арқылы навигация жасау

Кез келген QR-кодты телефонмен сканерлегенде, сайт автоматты түрде сол орынды танып, ойыншыны сол жерге орналастырады:

| Орын атауы | URL Параметрі | Мысалы |
|---|---|---|
| **Басты кіреберіс** | `?spot=entrance` | `https://site.com/?spot=entrance` |
| **Мектеп асханасы** | `?spot=cafe` | `https://site.com/?spot=cafe` |
| **Актовый зал** | `?spot=assembly` | `https://site.com/?spot=assembly` |
| **Спорт залы (2-қабат)** | `?spot=gym` | `https://site.com/?spot=gym` |
| **Кітапхана (3-қабат)** | `?spot=library` | `https://site.com/?spot=library` |
| **Кез келген кабинет** | `?room=105` | `https://site.com/?room=105` |

### 🖨️ Дайын A4 QR плакаттарын басып шығару:
Жоба ішіндегі **`qr_generator.html`** файлын браузерде ашыңыз. Онда өз сілтемеңізді енгізіп, мектеп қабырғасына ілетін көрнекі A4 плакаттарды бірден басып шығаруға болады.

```text
└── tools/                  # Көмекші генераторлар (Python)
```
