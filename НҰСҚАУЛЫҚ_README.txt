     АБАЙ АТЫНДАҒЫ ДАРЫНДЫ БАЛАЛАРҒА АРНАЛҒАН МЕКТЕП (ҚЫЗЫЛОРДА)
              2D ІШКІ НАВИГАЦИЯ ЖҮЙЕСІ (DIGITAL TWIN)
========================================================================

Бұл бағдарлама флешкадан (USB) кез келген ноутбукте немесе компьютерде
бірден жұмыс істейтіндей етіп жасалған.

------------------------------------------------------------------------
БАСҚА НОУТБУКТА ҚАЛАЙ ЗАПУСК БЕРЕМІЗ? (ӨТЕ ОҢАЙ):
------------------------------------------------------------------------
1. Флешканы жаңа ноутбукқа салыңыз.
2. "Project Abai school" папкасын ашыңыз.
3. Ішіндегі "Абай_мектебі_Іске_қосу.bat" (немесе "START.bat") файлына 
   екі рет басыңыз (Double click).
4. Болды! Браузер автоматты түрде ашылып, мектептің 2D навигациясы 
   қосылады!

------------------------------------------------------------------------
АВТОМАТТЫ ТҮРДЕ КЕРЕК ЗАТТАРДЫ ТАРТЫП АЛУ (AUTO-SETUP):
------------------------------------------------------------------------
* Сіздің флешкаңыздың ішіне барлық қажетті "Portable Python" пакеті
  (python_portable) АЛДЫН АЛА САЛЫНЫП ҚОЙЫЛДЫ!
* Яғни, басқа ноутбукта тіпті ИНТЕРНЕТ ЖОҚ болса да, флешка өз ішіндегі
  дайын автономды Python арқылы бірден іске қосылады.
* Ал егер бұл папка кездейсоқ өшіп қалса: жүйе интернеттен өзі автоматты
  түрде керекті файлдарды тартып алады (Auto-download).
* Егер интернет те, Python да жоқ болса: Windows жүйесінің өзінің
  ішкі жылдам сервері арқылы 100% офлайн қосылып кетеді.

------------------------------------------------------------------------
НЕГІЗГІ БАСҚАРУ БАТЫРМАЛАРЫ:
------------------------------------------------------------------------
* Қозғалу: W, A, S, D пернелері немесе Стрелкалар (← ↑ → ↓)
* Телефонда/Планшетте: Экрандағы джойстик немесе картаны түрту
* Қабаттар: 1, 2, 3 түймелері немесе Баспалдақ арқылы
* Іздеу: Үстіңгі іздеу жолына кабинет нөмірін (мыс: 104, 215, Асхана) жазыңыз
* Маршрут: Іздеуден кабинетті таңдасаңыз, ең қысқа жолды сызып көрсетеді
* QR Сканер: Қазіргі орынды анықтау немесе тез өту

Жұмысты аяқтау үшін:
Іске қосқан "START" қара терезесін жапсаңыз болғаны.
